## 第 2 轮

**用户**：从解方程组消元法学的，没接触过几何视角。算的时候没画面，就是按规则算。

**AI**：

## 诊断结果

**卡点类型**：直觉缺失 — 你把矩阵当成"计算规则"而不是"空间动作"。

解方程组教你的是**行视角**（每行一个方程），现在需要补**列视角**（每一列是基向量去向）。

## 修复

### 核心直觉：矩阵的列 = 基向量的新位置

以 2×2 矩阵为例：

```
[ a   c ]
[ b   d ]
```

原始空间有两个基向量：
- **î** = (1, 0) — x 轴方向
- **ĵ** = (0, 1) — y 轴方向

**矩阵乘法做的事：把 î 送到 (a,b)，把 ĵ 送到 (c,d)。所有其他点跟着一起动。**

```
原始 î = (1,0)  →  变换后 = 第一列 = (a,b)
原始 ĵ = (0,1)  →  变换后 = 第二列 = (c,d)
```

### 一个具体例子

矩阵：
```
[ 2   1 ]
[ 0   1 ]
```

- î = (1,0) → (2,0)，x 轴被拉长 2 倍
- ĵ = (0,1) → (1,1)，y 轴被倾斜到 45°

效果：**水平拉伸 + 剪切**。

那矩阵 × 向量 (3,2) 是什么？就是 3 个新 î + 2 个新 ĵ：
```
3 × (2,0) + 2 × (1,1) = (6,0) + (2,2) = (8,2)
```

### 几种常见矩阵的几何含义

| 矩阵 | 几何含义 |
|------|---------|
| `[k 0; 0 k]` | 均匀缩放 k 倍 |
| `[k 0; 0 1]` | 只沿 x 轴拉伸 |
| `[1 s; 0 1]` | 水平剪切（推箱子） |
| `[cosθ -sinθ; sinθ cosθ]` | 旋转 θ 度 |
| `[0 1; 1 0]` | 沿 y=x 反射 |
| 行列式 = 0 | 变换把空间"压扁"到更低维度 |

### 矩阵乘法 = 变换的复合

A×B = 先做 B 变换，再做 A 变换。这就是为什么不交换——先旋转再拉伸 ≠ 先拉伸再旋转。

## 常见误区

| 常见错误 | 为什么错 | 正确理解 |
|----------|---------|---------|
| 把矩阵当静态数字表 | 消元法训练只关注行操作 | 矩阵是**动作**——它的每一列告诉你基向量去了哪里 |
| 认为矩阵乘法规则是人为硬性规定 | 不知道为什么"行点乘列" | 规则来自"变换的复合"——行点乘列 = 追踪变换链中各分量的贡献 |
| 行列式只是计算套路 | 只背了公式不理解几何 | det = 变换后面积/体积的缩放倍率 |
