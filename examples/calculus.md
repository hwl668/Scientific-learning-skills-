# Calculus 示例

## 零基础类

**输入**：我刚上大一，老师讲了极限，但我连"极限"这两个字到底什么意思都不懂。
**适用 Skill**：`zero-base-learning`
**期望输出方向**：从"走路趋近墙壁"直觉出发 → 核心概念一句话 → ε-δ 定义的通俗翻译 → 一个简单数列极限例题 → 自测题

---

**输入**：我学了导数，会求导公式，但不知道导数本质是什么。
**适用 Skill**：`zero-base-learning` 或 `fuzzy-understanding`
**期望输出方向**：确认是"零基础"还是"模糊理解" → 直觉：车速表/切线 → 导数 = 局部变化率 → 例题 f(x)=x² 从定义推导导数 → 几何解释

## 模糊理解类

**输入**：我学了极限，但不知道 ε-N 定义到底在干什么。我能看懂符号，但不知道为什么要有这么复杂的定义。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断 → 可能卡在"为什么要这么形式化"的理解上 → 用"误差控制"的直觉修复 → ε 是你允许的误差范围，N 是"从第几项开始误差小于 ε" → 验证理解

---

**输入**：我知道泰勒公式，但不知道什么时候用。就是背了 sin x = x - x³/6 + ... 但不懂。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断 → 卡在"会背公式但不会用" → 核心修复：泰勒公式 = 用多项式模拟函数，阶数越高越精确 → 三个典型应用场景：求极限、近似计算、证明不等式 → 变式：什么时候用一阶近似（切线），什么时候要保留到三阶

## 深化类

**输入**：我学完了一元微积分，但我觉得我对"微积分基本定理"的理解还很表面。
**适用 Skill**：`deepening-learning`
**期望输出方向**：多视角 → 物理解读 (累积量 vs 变化率) → 证明思路 (黎曼和视角) → 与泰勒公式的联系 → 反例 (连续性必要) → 综合题

## 解题类

**输入**：求极限 lim(x→0) (e^x - 1 - x) / x²。我知道答案是 1/2，但我做不出来。
**适用 Skill**：`problem-solving`
**期望输出方向**：识别 0/0 型 → 比较多种方法（洛必达 vs 泰勒 vs 等价无穷小）→ 选最优方法 → 分步求解 → 方法策略总结 → 变式题

## 错题类

**输入**：题目求 f(x) = ln(x² - 1) 的定义域。我答 x > 1，正确答案是 x < -1 或 x > 1。
**适用 Skill**：`mistake-review`
**期望输出方向**：错因→条件漏看/解不等式漏负半轴 → 误区分析 → 正确思路对比 → 同类陷阱警示 → 检查清单 → 变式
