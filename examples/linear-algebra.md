# Linear Algebra 示例

## 零基础类

**输入**：我第一次学矩阵。老师说矩阵是一个数表，但我不知道为什么要把数排成表。
**适用 Skill**：`zero-base-learning`
**期望输出方向**：问题背景：线性方程组的系数自然形成了一张表 → 直觉：矩阵是"对空间的操作说明" → 最小例题：2×2 矩阵乘向量 → 自测题

---

**输入**：我学了矩阵乘法，但不知道为什么乘法规则定义得这么奇怪——行乘列然后加起来？为什么不能对应位置直接乘？
**适用 Skill**：`zero-base-learning` 或 `fuzzy-understanding`
**期望输出方向**：矩阵乘法 = 组合线性变换 → 先解释 A(Bx) = (AB)x → 矩阵乘法的定义是为了让"变换的组合"对应"矩阵的乘法"

## 模糊理解类

**输入**：我学了矩阵乘法，我会算 A×B，但我不知道我在算什么。老师说矩阵表示线性变换，但我不理解"变换"是什么意思。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：卡在"线性变换"的直觉理解 → 用平面上点的映射来可视化 → 2×2 矩阵怎么移动 (1,0) 和 (0,1) → 验证：矩阵 [2,0; 0,3] 把正方形变成什么 → 变式

---

**输入**：我学了秩（rank），但不知道 rank(A) 到底在数什么。我只记得怎么算（化行阶梯）。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：会算但不会解释——卡在概念含义 → 修复：秩 = 矩阵列空间的维数 = "矩阵真正能到达的方向数" → 用 3 个 2×2 矩阵对比（满秩/秩 1/零秩）→ 关联：秩和方程组的解空间维数的关系

---

**输入**：我不理解核空间（kernel）和像空间（image）。书上写 Ker(T) = {x | T(x) = 0}，Im(T) = {T(x) | x ∈ V}，但我不知道这有什么用。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：会背定义但不理解用途 → 直觉：核 = "被变换消灭掉的向量"，像 = "变换能到达的向量" → 维数公式 dim(Ker) + dim(Im) = dim(V) 的直觉含义 → 例题：一个 3×3 矩阵的核是直线还是平面

## 深化类

**输入**：我学了特征值和特征向量，会算 det(A - λI) = 0。但我不理解为什么特征值这么重要。
**适用 Skill**：`deepening-learning`
**期望输出方向**：多视角 → 几何：特征向量是"变换后方向不变的向量" → 对角化的意义 → 在微分方程、PageRank、PCA 中的应用 → 反例：不可对角化的矩阵 → 综合题

## 解题类

**输入**：已知 A = [[2,1],[1,2]]，求 A^n。我不会。
**适用 Skill**：`problem-solving`
**期望输出方向**：识别题型：矩阵幂 → 方法：对角化 A = PDP⁻¹ → A^n = PD^nP⁻¹ → 特征值 3 和 1 → 分步求解 → 总结 → 变式

## 错题类

**输入**：题目问"Ax = 0 有非零解的条件是什么"。我写"det(A) = 0 或 A 不满秩"。但老师说"当 A 是方阵时正确，非方阵呢？"
**适用 Skill**：`mistake-review`
**期望输出方向**：错因：条件限制没注意（默认方阵）→ 正确：对于 m×n 矩阵，非零解条件是 rank(A) < n → 检查清单 → 变式
