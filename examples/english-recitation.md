# English Recitation 示例

## 词汇记忆类

**输入**：我在背 "ambiguous" 这个词，总是记不住。
**适用 Skill**：`word-deep-dive`
**期望输出方向**：
1. 词根词缀拆分：ambi-（前缀：两边）+ -uous（形容词后缀）→"可以往两边走的"→ 模糊的
2. 近义词梯度：vague → ambiguous → equivocal
3. 形近词：ambidextrous（双手灵巧的）、ambivalent（矛盾的）
4. 搭配填空：The instructions were ____, so no one knew what to do.
5. 常见误区：和 vague 混用——ambiguous 是有多种可能解释，vague 是模糊不清
6. 标记模式：用户输入 `!ambiguous` 存入记忆，后续按间隔复习
7. 记忆锚点：ambi- = 两边 → 可以往左理解也可以往右理解 → 模棱两可

## 定义定理记忆类

**输入**：我要背中心极限定理的表述。
**适用 Skill**：`text-memorizer`
**期望输出方向**：
1. 内容分类：定义型，要点复述精度
2. 结构化拆分：条件（独立同分布 + 有限方差）→ 结论（标准化样本均值 → N(0,1)）
3. 关键词：独立同分布、有限方差、标准化、正态
4. 填空检测：逐层增加挖空比例
5. 问答检测：Q: 中心极限定理的核心结论？
6. 常见误区：中心极限定理 vs 大数定律（一个说分布趋近正态，一个说均值趋近期望）
7. 存入 `memory/text-memorizer/`，后续"出题"抽背

## 政治/历史知识点类

**输入**：我要背"五四运动的历史意义"，一共四条。
**适用 Skill**：`text-memorizer`
**期望输出方向**：
1. 内容分类：要点型，要求用自己的话复述
2. 结构化拆分：四条按"思想 → 政治 → 社会 → 国际"逻辑排序
3. 关键词压缩：每条 1 个关键词（"反帝反封建""新民主主义开端""思想解放""世界革命"）
4. 思维导图：树形结构
5. 问答检测：Q: 五四运动的思想意义？A: ...
6. 常见误区：把四条意义记串（核对每条关键词做定位验证）
7. 存入后输入"出题"随机抽背，薄弱点自动追踪
