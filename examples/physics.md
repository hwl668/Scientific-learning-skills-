# Physics 示例

## 零基础类

**输入**：什么是电场？老师说是"电荷周围存在的一种物质"，但什么是"一种物质"？我看不到。
**适用 Skill**：`zero-base-learning`
**期望输出方向**：问题背景：电荷之间为什么能隔着真空相互作用？→ 直觉：电场就是"电荷向外发出的影响力地图"（类似重力场）→ 核心概念：电场强度 E = F/q → 最小例题：一个点电荷周围的电场 → 自测

---

**输入**：我刚开始学物理，什么是"做功"？和日常说的"工作"一样吗？
**适用 Skill**：`zero-base-learning`
**期望输出方向**：直觉：做功 = 力在运动方向上产生了效果 → W = F·d·cosθ → 为什么垂直的力不做功（举着箱子走不算做功）→ 例题 → 自测

## 模糊理解类

**输入**：我学了动量守恒和动能守恒，但我总是搞不清什么时候守恒动量，什么时候守恒动能。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：概念混淆 → 核心区分：动量守恒是无条件的（无外力），动能守恒是有条件的（完全弹性碰撞）→ 弹性碰撞 vs 非弹性碰撞的对比表 → 例题 → 变式

---

**输入**：麦克斯韦方程组我会背，但它们到底在说什么？四个方程之间是什么关系？
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：会背但不理解物理含义 → 逐个修复：Gauss 定律 = 电荷产生电场，Faraday 定律 = 变化的磁场产生电场 → 它们共同描述了电磁场的完整行为 → 用统一场论视角连接

## 深化类

**输入**：经典力学我已经学完了，但我想理解拉格朗日力学和牛顿力学的根本区别。
**适用 Skill**：`deepening-learning`
**期望输出方向**：多视角：牛顿 = 力的视角，拉格朗日 = 能量的视角 → 为什么拉格朗日方法在处理约束时更优雅 → 最小作用量原理的直觉 → 简单例题对比两种解法

## 解题类

**输入**：一个质量为 m 的物体从半径为 R 的光滑半球顶端滑下，问在什么角度脱离球面？
**适用 Skill**：`problem-solving`
**期望输出方向**：识别题型：圆周运动 + 脱离条件 → 关键条件：脱离时 N = 0 → 能量守恒列方程 → 分步求解 → 方法总结（脱离类问题的统一处理）→ 变式

## 错题类

**输入**：题目问"质量为 m 的木块从斜面滑下，求加速度"。我直接用 g·sinθ，但老师扣了分说斜面本身也能滑动。
**适用 Skill**：`mistake-review`
**期望输出方向**：错因：模型建错（当成了固定斜面）→ 正确思路：斜面也在加速，需要同时考虑木块和斜面的运动方程 → 检查清单 → 变式
