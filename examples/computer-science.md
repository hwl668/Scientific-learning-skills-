# Computer Science 示例

## 零基础类

**输入**：什么是递归？老师说是函数调用自己，但我不知道这为什么有用。
**适用 Skill**：`zero-base-learning`
**期望输出方向**：问题背景：有些问题天然有自我相似的结构 → 直觉：俄罗斯套娃，每一层结构相同 → 核心：递归 = 把大问题拆成同类型的小问题 + 终止条件 → 最小例题：阶乘 n! = n × (n-1)! → 自测：斐波那契数列

---

**输入**：什么是"时间复杂度"？O(n) 是什么意思？我刚学编程。
**适用 Skill**：`zero-base-learning`
**期望输出方向**：直觉：不是"几秒"，而是"当输入翻倍时，时间怎么增长" → O(1) 不论输入多大都是常数时间，O(n) 输入翻倍时间翻倍，O(n²) 输入翻倍时间变成 4 倍 → 简单例子对比

## 模糊理解类

**输入**：我学了 Dijkstra 算法，会背模板。但我不理解它为什么能保证找到最短路，也不知道什么时候该用 BFS 什么时候用 Dijkstra。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：会背不会用 + 概念混淆 → 修复：Dijkstra 的核心思想是"每次扩展当前已知最近的节点"→ 为什么需要非负权 → 对比表：BFS（无权图）vs Dijkstra（非负权）vs Bellman-Ford（负权）→ 变式

---

**输入**：我学了指针（C 语言），但我不知道指针到底有什么用，为什么要搞得这么复杂。
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：卡在"为什么需要"→ 修复：指针解决三个问题——① 函数内修改外部变量 ② 动态内存 ③ 避免大对象拷贝 → 每个用一个最小例子 → 可视化内存布局

---

**输入**：我不理解"缓存局部性"（cache locality），为什么按行遍历矩阵比按列快？
**适用 Skill**：`fuzzy-understanding`
**期望输出方向**：诊断：不理解硬件层面的内存布局 → 修复：数组在内存中是按行存储的 → 按行访问是连续读（缓存友好），按列访问是跳跃读（缓存缺失）→ 可视化内存地址空间 → 代码演示

## 深化类

**输入**：我学了 ResNet，知道它引入了残差连接（skip connection），但我不理解为什么残差连接能解决梯度消失问题。
**适用 Skill**：`deepening-learning`
**期望输出方向**：多视角：信息流视角（梯度可以直接通过 skip connection 回传）、集成视角（ResNet = 浅层网络的指数级集成）→ 数学推导：带 skip connection 的反向传播梯度 → 对比实验思路：去掉残差连接的训练曲线

## 解题类

**输入**：LeetCode 上"最长回文子串"，我知道动态规划可以做，但状态转移方程写不出来。
**适用 Skill**：`problem-solving`
**期望输出方向**：识别题型：区间 DP → 关键：dp[i][j] 表示 s[i:j+1] 是否回文 → 转移：dp[i][j] = (s[i]==s[j]) and dp[i+1][j-1] → 边界条件 → 分步建表 → 方法总结 → 变式

## 错题类

**输入**：二叉树的中序遍历，我写了个递归版本提交了。面试官让我写迭代版本，写不出来。
**适用 Skill**：`mistake-review`
**期望输出方向**：错因：只会递归不会迭代（本质是对递归的调用栈理解不够）→ 修复：用显式栈模拟递归过程 → 对比递归和迭代的栈状态变化 → 检查清单：任何递归都能转迭代，需要手动维护栈 → 变式：用迭代做前/后序遍历
