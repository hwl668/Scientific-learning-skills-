# Scoring Rubric

本评测器用于检查 Skill 输出的**结构完整性和明显的教学规范问题**。它是确定性的规则评测，不验证学科事实是否正确，也不能证明真实学习效果。手写 smoke case 的高分只表示评分链路和格式约束可运行。

## 通用计分规则

- 每个 rubric 均为 10 个维度，每项 0–2 分，总分 20 分。
- 14 分及以上、“常见误区/关键误区”获得 2 分，且“避免空泛”获得 2 分才通过；任一硬门禁不满足时总分再高也失败。
- baseline 只展示，不计入通过率；一次运行若没有任何可计分样例则门禁失败。
- `concept` 与 `word` 保持兼容；新增 rubric 使用对应 Skill 的正式名称。
- “常见误区”是所有 rubric 的强制维度。

### 常见误区维度

满分必须使用标准表格，并至少包含 2 条真实误区：

| 常见错误 | 为什么错 | 正确理解 |
|---|---|---|
| 错误示例一 | 具体原因 | 正确理解一 |
| 错误示例二 | 具体原因 | 正确理解二 |

计分时表头和 Markdown 分隔线不算数据行；三列语义必须分别是错误、错因和正确理解。无关日志表、占位符行和重复行不能获得该维度满分。

## Rubric 配置

| Rubric | 适用场景 | 10 个评分维度 |
|---|---|---|
| `concept` | 旧版通用概念 Demo | 诊断、直觉、定义、例题、变式、误区、简洁、受众、总结、避免空泛 |
| `zero-base-learning` | 零基础概念学习 | 输入诊断、问题背景、直觉、定义、最小例题、自测迁移、误区、简洁、受众、避免空泛 |
| `fuzzy-understanding` | 模糊理解诊断 | 快速诊断、卡点结论、针对性修复、理解验证、变式、误区、简洁、受众、总结、避免空泛 |
| `deepening-learning` | 深化学习 | 基础确认、多视角、跨知识联系、推导、反例、应用、变式、误区、简洁、避免空泛 |
| `problem-solving` | 解题引导 | 题型识别、关键条件、建模、分步求解、步骤依据、总结、变式、误区、简洁、避免空泛 |
| `mistake-review` | 错题复盘 | 错误重现、错因归类、关键误区、正确思路、同类陷阱、检查清单、变式、简洁、受众、避免空泛 |
| `study-plan-builder` | 学习计划 | 约束校准、目标拆解、阶段、每日任务、资源、检测标准、复盘调整、误区、简洁、避免空泛 |
| `word` | 单词深挖 | 核心义项、搭配、词根词缀、易混词、近义梯度、考试针对性、误区、记忆锚点、简洁、避免空泛 |
| `text-memorizer` | 文本记忆 | 内容分类、结构拆分、思维导图、关键词、主动提取题、题型覆盖、复习追踪、误区、简洁、避免空泛 |

## JSONL Suite Schema

每行必须是一个 JSON 对象：

```json
{"id":"case-id","rubric":"problem-solving","text":"要评分的完整输出","baseline":false}
```

- `text`：必填，非空字符串。
- `id`、`label` 或 `name`：可选标识；显式提供时必须为非空字符串或整数，且在 suite 内唯一。
- `rubric`：可选，必须是上表中的名称或受支持的短别名；省略时使用 `concept`。
- `baseline`：可选，必须为布尔值；全部样例都标为 baseline 不会通过门禁。
- 非法 JSON、未知 rubric、空文本、错误字段类型和重复标识会直接报出文件与行号。

## 解读限制

规则评分只能作为快速回归门禁。发布质量结论时应另外报告：

1. 模型在冻结真实样例上的输出评测，而不是手写 Demo 得分。
2. 学科正确性的人审或独立 judge 结果。
3. 同构题、迁移题和延迟复测等学习效果指标。

不要把 smoke 通过率表述为路由准确率、模型遵循率或学习效果提升。
