# Skill 模板

复制此文件到 `.claude/skills/<your-skill-name>/SKILL.md`，修改内容。

```markdown
---
name: your-skill-name
description: 简短说明什么时候触发这个 skill，一句话。
---

# 目标

[这个 Skill 要解决什么问题？一句话。]

# 适用场景

- [场景 1]
- [场景 2]
- [场景 3]

# 输入判断

[打开 Skill 后，先做什么判断？问什么问题？]

# 执行流程

```
步骤 1 → 步骤 2 → 步骤 3 → ... → 步骤 N
```

## 1. 步骤名称

[做什么 + 为什么]

## 2. 步骤名称

[做什么 + 为什么]

...

# 输出格式

```markdown
## 部分 1
[内容说明]

## 部分 2
[内容说明]
```

# 反例：什么时候不要这样做

- [不要做 X]
- [不要做 Y]
- [不要做 Z]

# 测试样例

**输入**：[具体的用户输入]

**期望输出方向**：
1. [应该包含什么]
2. [应该包含什么]
3. [应该避免什么]
```
