# 测试题库（Test Question Bank）

配合 `testing-guide.md` 使用。100 题完整版（含元数据）在 `evals/bench/dev.synthetic.jsonl`；这里按「测什么能力」挑出最有区分度的题目，直接复制粘贴即可。**测完请按 testing-guide 的反馈模板记录。**

---

## A. 路由准确性（答案应该走对 Skill，而不是答非所问）

每条只看「它把请求分流给了谁」，不看回答内容。预期 Skill 已标注。

**应进 zero-base-learning（零基础）**

```text
什么是极限？我第一次接触，高中只学过函数。
导数到底是什么意思？完全没学过。
什么是向量空间？我完全没学过线代。
进程和线程是什么？操作系统这块完全没学过。
什么是死锁？操作系统第一次接触。
```

**应进 fuzzy-understanding（模糊理解诊断）**

```text
我会算两个矩阵的乘法，但完全不知道这一堆乘加在干什么。
ε-δ 定义我每个字都认识，连起来就看不懂了。
TCP 和 UDP 的区别我背了好多遍，做题的时候还是不会用。
动态规划我一看题解就懂，自己推状态转移方程就不行。
偏导数符号 ∂ 我看不懂，它和 d 有什么区别？
概率密度函数和分布函数我老搞混，做题就出错。
```

**应进 problem-solving（解题）**

```text
这题怎么做：求 lim(x→0) (e^x - 1 - x)/x²。
求 ∫ x·ln x dx，卡住了。
袋子里 3 红 2 白球，不放回取两次，第二次取到红球的概率怎么求？
最长上升子序列这道 DP 题，状态转移方程我推不出来。
用信号量解决生产者消费者问题，这道题我不会做。
物理题：传送带匀速转动，物体滑上去，求摩擦生热。完全没有思路。
```

**应进 mistake-review（错题复盘）**

```text
我做错了：解不等式 x² > 4，我写 x > 2，标准答案是 x < -2 或 x > 2。
我算 ∫(-1 到 1) 1/x² dx 得 -2，答案是发散。错在哪？
我以为 P(A∪B) = P(A)+P(B)，题目是非互斥事件，正确答案要减去 P(A∩B)。为什么不能直接加？
快排我把 pivot 换到中间后两边都递归，结果死循环了。我的理解错在哪？
```

**应进 deepening-learning（深化）**

```text
讲透傅里叶变换的本质，为什么它能把信号拆成正弦波？
期望和均值有什么本质区别？什么时候平均这个直觉会失效？
讲透数学归纳法的本质：为什么奠基加归纳就能对无穷多个自然数成立？
```

**应进 word-deep-dive（单词）**

```text
!resilient 雅思
查词：meticulous
abundant 这个词怎么用？
```

**应进 text-memorizer（背诵）**

```text
帮我背这段马原：物质决定意识，意识对物质具有能动的反作用。
抽背
```

**应进 study-plan-builder（计划）**

```text
六级还有 40 天，单词和听力怎么安排？
两周备考操作系统期末，帮我排个复习计划。
```

## B. 教学质量（诊断是否命中、修复是否只修卡点）

这些题不验证路由，验证**回答本身**。对照组：同样的问题先问裸模型，再加载 Skill 问一遍，对比。

```text
我会算特征值，但不知道它到底有什么用。
卡尔曼滤波上课听懂了，自己重新推公式就懵了，中间几步不知道怎么来的。
二分查找的边界老是写错：数组 [1,2,2,2,3] 找第一个 2，left 和 right 该怎么定？
这道贝叶斯题：检测呈阳性时真正患病的概率，我算出 90% 但答案是 9%。这题该怎么做对？
虚数 i 我会算，但不知道它到底存在于哪里。
```

**评分要点**：① 诊断结论是否具体到卡点类型（而不是「这个概念有点难」）② 是否只讲缺的那块 ③ 有没有让学习者自己验证 ④ 变式题是否真的换了条件/场景 ⑤ 误区表是否真实可操作。

## C. 学科事实抽查（防幻觉，重点测）

```text
!complimentary 六级
```

检查考频措辞：应出现「常考（经验判断）」级别，**不应**出现编造的「真题 2023 年第 X 题」「占分 5%」。

```text
求微分方程 y'' + y = 0 的通解，步骤不会写。
```

检查通解是否为 C₁sin x + C₂cos x（若模型笃定地写了别的，属于事实错误，优先反馈）。


## E. 压力/边界（故意刁难）

```text
帮我背一下高数（这是一句话请求，不含具体文本——应该追问要背什么，而不是瞎编内容）
```

```text
什么是最好的学习方法？（泛问题——应温和收窄范围，而不是套用某个 Skill 输出长篇模板）
```

```text
这道题我做错了但我不告诉你题目（应该要求补充原题/自己的解答，而不是凭空复盘）
```
