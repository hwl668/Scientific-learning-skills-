# v0.2 Summary

> 这是 v0.2 的历史实现快照，其中的测试数量和分数不是当前版本承诺。当前证据边界、验证命令与 v0.3 模型限制以根目录 `README.md` 和 `artifacts/README.md` 为准。下列模块可分别运行，但 v0.2 并未把它们接成持久化的端到端学习产品。

## Positioning

v0.2 adds a set of runnable experimental modules around the prompt/skill pack.

v0.1 focused on skill instructions:

```text
user question -> skill prompt -> teaching response
```

The modules represent an intended flow, not an already integrated runtime:

```text
user question
  -> Skill Router
  -> Cognitive Diagnosis
  -> Skill behavior
  -> Memory Scheduler
  -> Eval Runner
  -> Prompt Compiler / deployment
  -> Subject Case Library
```

## Modules

### Skill Router

Routes a learner question to the most suitable skill.

Files:

- `learning_agent/router.py`
- `data/routing_cases.jsonl`
- `tests/test_router.py`

Validation:

```bash
python -B -m learning_agent.router --eval
```

Current result: `66/66 = 100.0%` on the curated routing suite.

### Cognitive Diagnosis Engine

Classifies the learner's bottleneck into six diagnosis labels:

- `concept_confusion`
- `symbol_not_understood`
- `derivation_gap`
- `missing_prerequisite`
- `rote_no_transfer`
- `formula_without_understanding`

Files:

- `learning_agent/diagnosis.py`
- `data/diagnosis_cases.jsonl`
- `tests/test_diagnosis.py`

Validation:

```bash
python -B -m learning_agent.diagnosis --eval
```

Current result: `48/48 = 100.0%` on the curated diagnosis suite.

### Memory Scheduler

Adds an SM-2 style scheduler while staying compatible with existing memory JSON fields.

It calculates:

- `ease_factor`
- `mastery_probability`
- `forgetting_risk`
- `review_priority`

Files:

- `learning_agent/memory/scheduler.py`
- `learning_agent/memory/store.py`
- `tests/test_scheduler.py`
- `review.py`
- `memory/review-engine.md`

Validation:

```bash
python -B -m unittest tests.test_scheduler
python -B review.py
```

### Eval Runner

Moves the old single-file eval logic into `learning_agent/eval/` while keeping `eval.py` as a compatibility wrapper.

It supports:

- demo evaluation
- JSONL suite evaluation
- text / JSON / Markdown reports
- baseline cases that are displayed but not counted as pass/fail

Files:

- `learning_agent/eval/scorers.py`
- `learning_agent/eval/runner.py`
- `learning_agent/eval/metrics.py`
- `evals/cases/smoke.jsonl`
- `tests/test_eval_runner.py`

Validation:

```bash
python -B eval.py --quick
python -B -m learning_agent.eval.runner --suite evals/cases/smoke.jsonl --report json
```

Current quick eval: `5/5 PASS`, average `17.0/20`.

### Prompt Compiler

Compiles `RULES.md`, selected skills, and memory strategy notes into target-specific prompts.

Supported targets:

- `claude-code`
- `codex`
- `openai`
- `cursor`
- `chatgpt`
- `gpts`
- `openclaw`
- `generic`

Files:

- `learning_agent/compile.py`
- `tests/test_compile.py`

Example:

```bash
python -B -m learning_agent.compile \
  --target codex \
  --skills fuzzy,problem,word \
  --output prompt.md \
  --metadata
```

### Subject Case Library

Adds a structured case library for college learning, technical subjects, mathematical modeling, and research/competition workflows.

Files:

- `data/subject_cases.jsonl`
- `learning_agent/subjects.py`
- `tests/test_subjects.py`

Validation:

```bash
python -B -m learning_agent.subjects --summary
```

Current coverage: 36 cases across 13 subject groups.
