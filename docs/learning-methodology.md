# 学习方法论

本项目所依据的学习科学原理。

> **适用边界**：下列研究用于解释设计选择，并不构成 Scientific Learning Skills 的效果证明。把研究中的教学条件映射为 Skill 指令只是待验证假设；本项目尚未提供真实学习者的受控实验、迁移测验或延迟复测。

## 核心理念来源

### 认知负荷理论 (Cognitive Load Theory)

学习者的工作记忆容量有限。当信息呈现方式不当（如符号密集但没有解释、例题缺失直接给抽象定义），认知负荷超载，学习就会失败。

**对应的设计选择**：
- 直觉先于定义，作为减少不必要表征负担的待验证设计假设
- 最小例题，降低外在认知负荷
- 分步推演，避免信息过载

### 建构主义 (Constructivism)

学习者不是被动接收知识，而是在已有认知结构上主动建构新的理解。如果前置知识缺失或错误，新的知识无法正确"挂靠"。

**对应的设计选择**：
- 诊断卡点（哪个前置环节断了）
- 联系已有知识（这个新知识和你知道的 X 有什么关系）
- 多视角解释（同一概念挂靠到不同认知框架上）

### 提取练习效应 (Retrieval Practice Effect)

在延迟测验等条件下，主动从记忆中提取信息（如自测、填空）可能比单纯重复阅读更有利于保持；效果会受材料、反馈与测验间隔影响。

**对应的设计选择**：
- 自测题替代总结
- 填空/问答检测替代重读
- 变式训练替代原题重做

### 间隔效应 (Spacing Effect)

大量研究显示，分散练习通常比集中练习更有利于延迟保持，但最合适的间隔取决于目标保持时长和任务。

**对应的设计选择**：
- 背诵 Skill 中的间隔复习提醒
- 学习计划中的阶段性复习节点

### 变式理论 (Variation Theory)

在不同情境、条件和反例之间比较，有助于学习者区分概念的核心特征与表面特征；本项目把它实现为变式与反例提示。

**对应的设计选择**：
- 每个 Skill 强制要求变式训练
- 反例辨析是解释的固定环节
- 深化学习中强调"多视角看同一概念"

## 六个核心学习环节

```
诊断卡点 → 重构理解 → 例题验证 → 变式迁移 → 错因复盘 → 间隔复习
```

每个环节在学习中的作用：

| 环节 | 作用 | 缺失时的后果 |
|------|------|-------------|
| 诊断卡点 | 定位问题的根源 | 重复学已懂的内容，浪费时间 |
| 重构理解 | 修复错误或缺失的认知 | 新的误解堆在旧的误解上 |
| 例题验证 | 确认理解能落地 | "我以为我懂了" |
| 变式迁移 | 确认理解不是表面记忆 | 换一道题就不会 |
| 错因复盘 | 把错误变成学习资源 | 同样的错误反复出现 |
| 间隔复习 | 巩固长期记忆 | 学完就忘 |

## 学习进阶模型

```
零基础 → 模糊理解 → 清晰理解 → 熟练应用 → 深刻理解
   ↑           ↑           ↑           ↑           ↑
zero-base   fuzzy-      问题-      变式        deepening
-learning   understanding solving    训练        -learning
```

不同阶段需要不同的学习策略和 Skill 支持。

## 与其他方法的对比

### vs. 费曼学习法

费曼学习法的核心是"教给别人"。我们认同这个方向（"用自己的话说"贯穿所有 Skill），但更进一步强调了诊断、结构化和变式训练。

### vs. 刻意练习 (Deliberate Practice)

刻意练习强调在能力边界外有反馈地训练。我们认同这个方向，但更强调"找准边界"——不是盲目做难题，而是先诊断卡点再做针对性训练。

### vs. Bloom 二西格玛问题 (2 Sigma Problem)

Bloom 报告的是特定条件下的人类一对一辅导与掌握学习结果，不能直接外推为 AI 或本项目能达到同等效果。本项目只借鉴其中的频繁诊断、反馈与掌握检查思路；是否产生学习增益仍需单独实验。
